TRAK 3.0.7

BUFFER / TRACKSERVER
- Le buffer SD reste persistant et FIFO.
- Les positions LIVE ne sont plus bloquées derrière le backlog FIFO.
- Le LIVE conserve son intervalle d'envoi normal, même lorsque le buffer est non vide.
- Le FIFO est rattrapé entre deux transmissions LIVE.
- Chaque position bufferisée conserve maintenant date + heure GNSS complètes.
- Les transmissions Trackserver ajoutent le timestamp Unix de capture via le paramètre timestamp.
- Une position LIVE qui échoue est ajoutée au FIFO comme auparavant.
- Le compteur de consommation continue de comptabiliser le mois réel d'envoi.
- Le format du buffer passe en version 2 pour intégrer l'heure GNSS. Un ancien buffer v1 est recréé proprement.

OBJECTIF
- Éviter qu'un backlog de plusieurs centaines de positions immobilise le suivi temps réel.
- Permettre à Trackserver de reconstruire la chronologie grâce au timestamp GNSS original.


AJUSTEMENT FINAL DU SCHEDULER
- L'échéance LIVE reste indépendante du rattrapage FIFO.
- Le LIVE est toujours traité avant le FIFO lorsqu'il est dû.
- Une garde de 2 s empêche de démarrer une requête FIFO juste avant un LIVE.
- Le délai du prochain LIVE repart après la tentative HTTP réelle.
- Le FIFO continue de progresser entre deux LIVE lorsqu'il reste du temps.
