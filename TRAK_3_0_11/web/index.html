À propos

The Open-Source GPS Tracker

TRAK est un tracker GPS autonome conçu pour le suivi de véhicules, motos et équipements mobiles.

Position GNSS, connexion Wi-Fi / 4G, envoi Trackserver, statistiques réseau et données de mouvement sont regroupés dans une interface simple et lisible.
