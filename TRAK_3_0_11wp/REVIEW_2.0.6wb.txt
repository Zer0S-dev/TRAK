TRAK 2.0.6wb — revue de correction
===================================

Corrections appliquées :
1. DevLog.h : inclusion de Config.h avant l'utilisation de DEV_LOG.
2. DevLog.h : printf() passe par Print::write(buffer,size), qui conserve le
   dispatch vers write(uint8_t) et donc la duplication Serial + SD.
3. ModemManager.cpp : modemDevSerial -> modemSerial.
4. TRAK_2_0_6wb.ino : modemDevSerial -> modemSerial.
5. Config.h : ajout de WIFI_SCAN_COOLDOWN_MS = 60000 ms.
6. TRAK_2_0_6wb.ino : PREFERRED_NETWORK_RETRY_MS utilise la constante.
7. README.md et RELEASE_NOTES_2.0.6wb.txt mis à jour.

Contrôles statiques :
- aucune référence modemDevSerial dans les sources C/C++/INO.
- WIFI_SCAN_COOLDOWN_MS défini dans Config.h et utilisé dans le .ino.
- FIRMWARE_VERSION = 2.0.6wb.
- DEV_LOG est défini dans Config.h et consommé par DevLog.cpp.
- DevLog reste indépendant du port matériel du modem.

Limite :
La compilation complète nécessite l'environnement Arduino ESP32 3.3.11 et les
bibliothèques matérielles du TRAK. La revue statique ne remplace pas le build
sur la machine Arduino IDE.
